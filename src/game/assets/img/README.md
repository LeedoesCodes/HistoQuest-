# Image assets

Drop PNGs here and they auto-load — no code change needed.

Path → in-game key:  `mactan/char_lapulapu.png` → key `mactan/char_lapulapu`

Folders: `common/` (shared, e.g. the ally), `mactan/`, `pugad_lawin/`,
`datu_bago/`. Each arc's full-screen background is `<arc>/bg.png`.

See docs/asset-brief.md for sizes, style, and the full list.
